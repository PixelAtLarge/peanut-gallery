Step 1

Leave notes on the real page

This is the widget, running on a sample checkout. Notes stick to the element you click, so the context survives.

Nothing you type leaves your browser in this demo.

A reviewer already left two notes (the numbered pins). Add your own:
  1. Press Comment in the toolbar at the bottom right of the checkout.
  2. Click anything on the page and type a note.
  3. Press Review, then Submit.

Step 3

Claude groups the feedback and makes the change

Run npx peanut-gallery review. Notes are clustered into proposals, then a coding agent implements each one on its own branch, inside your design system.

Claude doesn't run live in this demo. In your repo it works from your reviewers' notes, using your own Claude login or API key. Below is a real run on the two example notes.

Recorded run · Nov 7, 2026 · Claude Sonnet 5.5 on the two example notes, in a test repo with a tokens.css design system and a CLAUDE.md. Nothing below is mocked up.

Make "Pay now" the primary CTA and show the total on it

The button reads "Pay now" with no amount. Put the total in the label and give it primary styling so the next step is clear.

1 reviewer · 1 noteeffort: smallconfidence 70%

Increase prominence of the order total

The total in the order summary feels buried. Enlarge it and give it more weight so it stands out, without changing the layout.

1 reviewer · 1 noteeffort: smallconfidence 75%
index.html
-  <button class="btn" data-testid="pay">Pay now</button>
+  <button class="btn btn--primary" data-testid="pay">Pay <span data-total-ref></span></button>
+  <script>/* Pay button amount mirrors the order total so the two cannot drift apart. */</script>

styles.css
+/* Primary variant: --accent darkened with --ink so --on-accent text meets 4.5:1 (plain --accent is ~4.3:1). */
+.btn--primary { font-weight: 600; background: color-mix(in srgb, var(--accent), var(--ink) 15%);
+                border-color: transparent; color: var(--on-accent); }
+.btn--primary:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }

From the pull request

Claude noticed white text on the brand accent fails contrast, so it darkened the fill using the existing tokens and flagged that a designer may want a dedicated token. It used no raw colours, reused the .btn pattern from CLAUDE.md, and couldn't touch tokens.css.

Step 5

Not quite right? Ask for options

Your turn

Try it on your prototype

Works on any hosted page with a GitHub repo. AI runs on your own Claude Code login or Anthropic API key, with a spending cap you set.

1. Add the CLI and set up your repo

npm i -D peanut-gallery && npx peanut-gallery init

2. Add the widget to your prototype

<script src="https://unpkg.com/@pixelatlarge/peanut-gallery-widget/dist/peanut-gallery.global.js" data-repo="you/your-repo" data-activation="query"></script>

3. When feedback comes in

npx peanut-gallery review
