# Greenhouse shop (React example)

- React 19 + React Router 7 + Vite. Pages live in `src/pages`, shared pieces in `src/components`.
- Colours, radii and spacing come from the CSS variables in `src/styles/tokens.css`. Never hard-code hex values.
- Buttons use the `.btn` class; variants add a modifier class (`.btn-primary`, `.btn-danger`) defined in `src/styles/app.css`, never inline styles.
